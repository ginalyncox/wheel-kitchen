# Wheel + Kitchen

A research-backed field guide to cooking in a standard, non-adapted kitchen from a manual wheelchair. Published under [Gina Makes](https://ginamakes.dev).

## What this is

An 11-page editorial site covering kitchen setup, stovetop and oven safety, prep technique, an adaptive toolkit, meal planning, fire and burn safety (drawing on the FEW program at University of Illinois), cleanup, groceries, troubleshooting, and a full source list.

Every recommendation traces to a named source — occupational-therapy literature, ADA/universal-design specifications, or wheelchair-using cooks writing publicly about their own kitchens. No AI-generated tips.

## Stack

- Static HTML, CSS, and a tiny JS file (theme toggle, mobile nav)
- No framework, no build step besides a small Python stamper (`_build.py`) that wraps content fragments in `pages/` with a shared header and footer
- Fonts: Fraunces (display) + Work Sans (body), via Google Fonts
- Fully responsive, WCAG-minded (skip link, focus rings, semantic headings, alt text), light and dark modes

## Local development

```bash
# Rebuild pages after editing anything in pages/
python _build.py

# Serve locally
npx serve . -l 3000
# or
python -m http.server 3000
```

Edit the fragments in `pages/*.html`, then re-run `_build.py`. The built pages are written to the project root next to `index.html`.
